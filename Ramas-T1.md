## Estructura oficial del ciclo baseline del Protocolo ISA  
### Por Estudio_WiiDu

---

# Introducción

El ciclo T1 del Protocolo ISA está compuesto por siete ramas.  
Cada rama representa una fase del baseline y debe documentarse de forma independiente para garantizar claridad, trazabilidad y consistencia metodológica.

Este documento actúa como índice maestro del ciclo T1.

---

# Las 7 ramas del ciclo T1

## 1. Preparación T1  
Documento: `Preparacion-T1.md`  
Define las señales mínimas y la documentación necesaria antes de ejecutar el dataset ISA.

## 2. Lanzamiento T1  
Documento: `Lanzamiento-T1.md`  
Explica cómo se ejecutan los 21 prompts del dataset en los tres motores IA.

## 3. Registro T1  
Documento: `Registro-T1.md`  
Establece cómo se documentan los 63 tests y cómo se clasifican los indicadores ISA.

## 4. Interpretación T1  
Documento: `Interpretacion-T1.md`  
Analiza los resultados del baseline por motor y por indicador.

## 5. Informe T1  
Documento: `Informe-T1.md`  
Resume los resultados del ciclo T1 y presenta conclusiones técnicas.

## 6. Hoja de mejoras T1 → T2  
Documento: `Mejoras-T1-T2.md`  
Define las acciones necesarias para mejorar los indicadores en el ciclo T2.

## 7. Validación T1  
Documento: `Validacion-T1.md`  
Confirma que el ciclo T1 está completo, consistente y listo para iniciar T2.

---

# Objetivo del documento maestro

Este índice permite:

- navegar fácilmente por las 7 ramas  
- mantener orden editorial en GitHub  
- facilitar auditorías internas y externas  
- asegurar consistencia metodológica  
- preparar la estructura para T2 y T3  

---

# Conclusión

Las 7 ramas del ciclo T1 forman el baseline del Protocolo ISA.  
Este documento maestro centraliza su estructura y facilita la comprensión del proceso completo.
