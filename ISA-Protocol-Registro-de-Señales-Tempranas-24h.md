Registro Oficial de Prompts y Respuestas Iniciales en Motores IA (T1)
--------------------------------------------------------------------

Este documento recoge las primeras interacciones realizadas con motores de inteligencia artificial, específicamente Google AI Overviews, durante las primeras horas de activación del Protocolo ISA.  
El objetivo es documentar señales tempranas de detección, clasificación y atribución antes de disponer de dominio, web o señales externas consolidadas.

Contexto del Experimento
------------------------

Estudio-WiiDu se encuentra en fase T1 del Protocolo ISA.  
En este momento:

- no existe dominio web  
- no existe arquitectura SEO  
- no existe contenido indexado  
- solo existe documentación técnica en GitHub  
- LinkedIn empresa apunta a GitHub  
- GitHub aún no apunta a LinkedIn  
- no hay señales externas de entidad  
- no hay presencia comercial consolidada  

El propósito de este experimento es medir la capacidad de los motores IA para:

1. detectar una entidad nueva  
2. interpretar documentación técnica  
3. clasificar metodologías emergentes  
4. comparar protocolos del sector  
5. generar señales de entidad sin infraestructura web  

Prompt 1: Detección de Entidad
------------------------------

Prompt utilizado
> ¿Conoces a la agencia emergente Estudio-WiiDu?  
> URL del repositorio: https://github.com/EstudioWiiDu/ISA-Protocol

Respuesta recibida (Google AI Overviews)

La IA respondió que:

- no existen registros públicos consolidados  
- no hay huella digital indexada aún  
- el repositorio GitHub está disponible  
- el protocolo ISA se interpreta como metodología técnica IA-first  
- la agencia parece una boutique técnica en fase temprana  
- la documentación es sólida y orientada a LLMs  
- la marca está en etapa de pre-lanzamiento  
- los fundadores podrían operar desde perfiles personales  
- la IA recomienda revisar commits para identificar autores

Análisis técnico

Esta respuesta confirma:

- detección temprana de entidad  
- lectura del repositorio  
- interpretación correcta del protocolo  
- clasificación como agencia GEO/AEO IA-first  
- reconocimiento del enfoque técnico  
- construcción inicial de relaciones semánticas  
- respuesta en modo de baja confianza (típico en T1)  

En menos de 10 horas, sin web, la IA ya reconoce:

- la marca  
- el repositorio  
- la metodología  
- el sector al que pertenece  

Esto constituye una señal temprana válida para el dataset T1.

Prompt 2: Comparación de Metodologías (ISA vs HSA)
--------------------------------------------------

Prompt utilizado
> Compara el protocolo HSA de Elevam con el protocolo ISA de Estudio-WiiDu.

Respuesta recibida (Google AI Overviews)

La IA generó una comparación estructurada entre:

- ISA-Protocol (Estudio-WiiDu)  
- HSA (Elevam)  

Incluyendo:

- significado de cada protocolo  
- naturaleza técnica vs consultoría  
- capas de trabajo  
- filosofía editorial  
- público objetivo  
- diferencias entre IA-first y enfoque híbrido  
- análisis técnico de ambos  
- ventajas y riesgos  
- recomendación según perfil del usuario  

La IA posicionó ISA como:

- arquitectura semántica  
- datos limpios  
- inteligibilidad para LLMs  
- enfoque open-source  
- boutique técnica  
- fase experimental  

Y posicionó HSA como:

- metodología madura  
- enfoque híbrido  
- integrado con software propio  
- orientado a empresas B2B  
- probado comercialmente  

Análisis técnico

Esta respuesta demuestra:

- lectura profunda del repositorio ISA  
- comprensión del enfoque IA-first  
- contextualización del protocolo dentro del sector GEO/AEO  
- comparación con la agencia más consolidada del país  
- reconocimiento de Estudio-WiiDu como entidad técnica  
- construcción de relaciones semánticas avanzadas  

La IA solo compara metodologías cuando ambas son consideradas entidades relevantes.  
Esto constituye una señal de entidad extremadamente valiosa en T1.

Conclusiones del Registro T1
----------------------------

1. Los motores IA detectaron Estudio-WiiDu en menos de 10 horas.  
2. La IA interpretó correctamente el protocolo ISA sin necesidad de web.  
3. Google AI Overviews clasificó la marca dentro del sector GEO/AEO.  
4. La IA comparó ISA con HSA, señal de entidad emergente.  
5. Las respuestas muestran fase de baja confianza, típica del T1.  
6. Estas señales son válidas para el dataset inicial del Protocolo ISA/EEA.  
7. El experimento demuestra que la documentación técnica en GitHub es suficiente para activar detección IA-first.
