# Tiempo estimado de detección en Perplexity

El tiempo que tarda Perplexity en detectar una entidad depende de la calidad del contenido y de la coherencia del naming.

Estimaciones generales:

- Documentación mínima: entre 2 y 4 semanas  
- Documentación media: entre 7 y 14 días  
- Documentación IA-first completa: entre 48 y 72 horas  
- Con GitHub Pages activo: incluso menos

En el caso de Estudio‑WiiDu, con la documentación ya publicada:

La ventana realista es entre 48 horas y 7 días.

Perplexity es el motor más rápido en:

- leer repositorios GitHub  
- interpretar archivos Markdown  
- detectar definiciones claras  
- reconocer naming consistente  
- identificar señales IA-first  
- relacionar documentos entre sí

# Señales que utiliza Perplexity para decidir que una entidad “existe”

Perplexity no rastrea como Google.  
Perplexity interpreta.

Las señales principales que analiza son:

- definiciones claras  
- documentación extensa  
- naming repetido en varios documentos  
- estructura IA-first  
- fragmentos citables  
- URLs accesibles  
- relación entre documentos  
- coherencia editorial  
- señales de entidad en varias capas  

Cuando estas señales aparecen de forma consistente, Perplexity empieza a reconocer la marca como entidad.
