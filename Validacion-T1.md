# Introducción

La Validación T1 es la fase final del ciclo baseline del Protocolo ISA.  
Su objetivo es confirmar que todas las etapas del ciclo T1 se han completado correctamente y que los datos obtenidos son válidos, consistentes y utilizables para el ciclo T2.

Sin validación, el baseline no puede considerarse cerrado.

---

# Elementos que deben validarse

## 1. Ejecución completa del dataset ISA
- Los 21 prompts se ejecutaron en los 3 motores IA.  
- No se modificó ningún prompt.  
- No se repitió ningún test.  
- No se corrigió ninguna respuesta.

## 2. Registro completo de los 63 tests
- Todas las respuestas están guardadas.  
- Todos los indicadores están clasificados (P, Q, R, Top 3, SoM).  
- No hay tests omitidos.  
- No hay respuestas incompletas.

## 3. Panel de resultados T1
- Los datos están organizados por motor.  
- Los datos están organizados por bloque (Marca, Servicio, Subservicio).  
- Los indicadores están calculados correctamente.

## 4. Informe T1
- El informe está redactado.  
- Incluye análisis por motor.  
- Incluye análisis por indicador.  
- Incluye conclusiones claras.

## 5. Hoja de mejoras T1 → T2
- Las acciones están definidas.  
- Las mejoras están priorizadas.  
- Las tareas están asignadas (si aplica).  
- Las señales faltantes están identificadas.

---

# Criterios de validación ISA

Un ciclo T1 se considera **válido** cuando:

- todos los tests están registrados  
- todos los indicadores están evaluados  
- el informe está completo  
- la hoja de mejoras está definida  
- no hay vacíos de datos  
- no hay errores metodológicos  
- no hay prompts sin ejecutar  
- no hay respuestas sin clasificar  

---

# Resultado esperado

Cuando T1 está validado:

- el baseline queda oficialmente cerrado  
- la marca tiene un punto de partida medible  
- las mejoras para T2 están claras  
- los motores IA han sido evaluados correctamente  
- el ciclo T2 puede iniciarse sin riesgo metodológico  

La Validación T1 garantiza que el Protocolo ISA se ejecuta con rigor y consistencia.
