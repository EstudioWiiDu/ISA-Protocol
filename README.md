# Introducción

Este repositorio contiene la documentación oficial del **Protocolo ISA**, la metodología desarrollada por Estudio_WiiDu para optimizar la presencia de una marca en motores de inteligencia artificial generativa y en sistemas de Google.

ISA integra tres capas:

- **Interpret** — claridad + AEO  
- **Search** — SEO técnico + rastreo + indexación  
- **Attribute** — GEO + señales de entidad + URL correcta  

El objetivo del protocolo es que una marca sea:

- entendida  
- encontrada  
- citada  
- atribuida correctamente  

por motores IA como ChatGPT, Gemini, Perplexity y Google AI Overviews.
